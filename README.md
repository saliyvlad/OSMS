## Описание
Данный репозиторий содержит решение первой практической работы по теме: *"Временная и частотная формы сигналов. Преобразования Фурье. Дискретизация сигналов"*.

## Выполненные задачи
- Генерация и визуализация непрерывного периодического сигнала (Вариант 18).
- Расчет максимальной частоты спектра и минимальной частоты дискретизации по теореме Котельникова.
- Оцифровка сигнала, выполнение прямого дискретного преобразования Фурье (БПФ) и оценка требуемого объема памяти.
- Восстановление аналогового сигнала и анализ ошибки (MSE) при базовой и увеличенной в 4 раза частоте дискретизации.
- Анализ реального голосового сигнала: чтение WAV-файла, прореживание (downsampling), воспроизведение и сравнение спектров.
- Оценка влияния разрядности АЦП (квантование по уровню 3–6 бит) на спектр сигнала.
- **Дополнительное задание:** Аддитивный синтез мелодии начального проигрыша песни «Проклятый старый дом» (Король и Шут) исключительно с использованием функций `sin` и `cos` (демонстрация теоремы Фурье).
